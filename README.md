# 网站的主要目的 
该网站主要用于展示考试笔记和备考知识点教程。实体是：高考、自考本科以及考研的markdown笔记，同时网站将接入LLM的API，让用户可以在界面内用站内AI答疑。

# 项目核心技术
## 1. 邮箱登录
用户必须先进行邮箱登录，才能看到里面的笔记.注意当前邮箱登录是你在哪一个端点击验证邮箱地址，就会在哪一个端登录。更完善的邮箱登录功能还在开发中
## 2. 技术栈
技术栈：**React + Vite**；公式用 `react-markdown` + `remark-math` + `rehype-katex`（KaTeX 引擎）。

# 网站功能
## 1. 新增笔记
1. 在 `public/notes/` 里新建一个文件夹（文件夹名 = 侧边栏标题）。
2. 把 `.md` 和它用到的图片**放进同一个文件夹**。图片在 `.md` 里直接写文件名即可，
3. 使用GitHub desktop同步至你的部署服务器
4. 重新部署，界面上就有新的笔记了
